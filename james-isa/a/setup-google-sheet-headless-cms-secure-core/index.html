Setup Google Sheet sebagai Headless CMS Secure Core: Kredensial Tetap di Server

Cara setup Google Sheet sebagai Headless CMS dengan Secure Core: Service Account JWT, kredensial hanya hidup di Cloudflare Pages Function, tidak pernah ke browser. Zero Leakage Verified.

Masalah: Kredensial di Browser = Bocor

Banyak tutorial ajarkan GOOGLE_API_KEY taruh di frontend JavaScript. Ini bahaya — siapa pun bisa lihat di View Source.

BROWSER fetch('/api/articles')
┆
CLOUDFLARE PAGES FUNCTION (env.GOOGLE_SHEET_ID + JWT)
┆
GOOGLE SHEETS (private, share hanya ke service account)

Langkah Setup 15 Menit

  1. Buat Service Account di GCP: IAM & Admin > Service Accounts > Create > Role Viewer
  2. Buat JSON Key: Keys > Add Key > JSON
  3. Share Sheet ke email service account (viewer only)
  4. Env di Cloudflare Pages: GOOGLE_SHEET_ID, GOOGLE_SERVICE_ACCOUNT_JSON, GOOGLE_SHEET_RANGE
  5. Function: Copy functions/api/articles.ts dari ZIP final - sudah ada JWT signing + cache 5 menit
LokasiKredensialAman?
Frontend (salah)GOOGLE_API_KEY di JS❌ Bocor
Backend Function (benar)Service Account JWT di env✅ Aman

Zero Leakage Verified: Badge di footer jimkoto.my.id karena kredensial tidak pernah ke browser.
